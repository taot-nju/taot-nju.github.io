12. FlashInfer 是什么

FlashInfer 是一个面向大语言模型推理的高性能 GPU Kernel 库。

它主要优化：

  • Attention；

  • KV Cache；

  • top-k 采样；

  • top-p 采样；

  • normalization；

  • 推理中的其他 CUDA 操作。

它提供高度优化的 CUDA Kernel，用于提升大模型推理速度。

13. 什么是 JIT

JIT 是 Just-In-Time Compilation，即即时编译。

意思是：

程序不是在安装时提前编译所有代码，而是在实际运行时，根据当前机器环境现场进行编译。

编译时可能根据：

  • GPU 型号；

  • GPU 架构；

  • CUDA 版本；

  • 数据类型；

  • Block 大小；

  • Kernel 参数；

生成适合当前机器的代码。

例如 RTX 3090 的 Compute Capability 是 8.6，编译参数可能包含：

xxxxxxxxxx
2
1
compute_86
2
sm_86

13.1 JIT 的优点

  • 能针对当前 GPU 优化；

  • 支持更多动态组合；

  • 不必提前发布所有二进制版本；

  • 可能获得更好的性能。

13.2 JIT 的缺点

  • 第一次启动可能较慢；

  • 依赖本地编译环境；

  • 容易暴露 nvcc、头文件、编译器和链接库问题。

大白话：

预编译像购买成品家具，拿来就能用。 JIT 像到现场按房间尺寸定制家具，因此必须有木工、工具、图纸和材料。

19. 最重要的三句话

第一句：

torch.cuda.is_available() == True 只说明 PyTorch 能使用 GPU，不说明 CUDA 编译环境完整。
